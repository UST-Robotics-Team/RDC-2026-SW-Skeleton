# RDC 2026 -- Skeleton Code

Starting skeletons for the UST Robotics Team RDC 2026. There are two independent
STM32 project folders:

| Project                               | Board                 |
| ------------------------------------- | --------------------- |
| [`MainBoard/`](MainBoard/README.md)   | STM32F405             |
| [`Controller/`](Controller/README.md) | Blue Pill (STM32F103) |

Each `README.md` of the individual project folder points you to the resources
you need to work on each project for RDC. Read through the resources, catch-up
on tutorials, and look for help online when you're stuck.

> [!Important]
>
> Remember to open the **individual folders** in VS Code, rather than this outer
> folder.
